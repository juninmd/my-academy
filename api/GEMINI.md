# Project Rules & Standards

## Backend (`my-academy-api`)
- **Package Manager**: MUST use `pnpm`.
  - Install: `pnpm install`
  - Run: `pnpm run <script>`
  - Add: `pnpm add <package>`
- **Forbidden**: Do NOT use `npm` or `yarn` for package management in this directory to avoid lockfile conflicts.

## Frontend (`my-academy`)
- **Framework**: Flutter
- **Package Manager**: `flutter pub`

## Testing
- **E2E**: Playwright (located in `e2e-tests/`)
